5 mistakes that make a humidifier hurt instead of help

  1. Never cleaning it. MedlinePlus says to drain and clean a humidifier daily, because bacteria can grow in standing water. Do a deeper clean every few days.
  2. Using tap water. Tap water has minerals that build up inside the unit. Distilled water, or demineralization tablets, keeps it cleaner for longer.
  3. Running it nonstop with no humidity reading. Aim for 30-50% humidity. If windows or walls stay wet to the touch, turn it down, because damp rooms invite mold.
  4. Putting it right next to the bed. MedlinePlus advises keeping it several feet away from the bed.
  5. Buying warm mist for a kids' room. MedlinePlus recommends cool mist, especially for children, because warm mist can cause burns if someone gets too close.
